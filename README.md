# AccessoryBatteryTray

Утилита для Windows 11 x64. Цель MVP — показывать в трее по одной иконке с зарядом для каждого подключённого Bluetooth-аксессуара, с которого удалось прочитать процент. Сейчас доступны два консольных режима для проверки обнаружения, подключения и чтения заряда.

## Запуск

Нужен .NET 10 SDK. Выполняй команды в PowerShell из папки проекта.

Разовое перечисление подключённых Bluetooth Classic и LE устройств и чтение заряда через GATT для LE:

```powershell
dotnet run -- --diagnose
```

Режим также показывает сопряжённые устройства, исключённые селектором подключённых. При ошибке чтения выводит операцию и причину.

Наблюдение за подключениями через `DeviceWatcher`:

```powershell
dotnet run -- --watch
```

Режим выводит первоначальный список подключённых устройств, события подключения и отключения, а также результат чтения заряда LE при каждом подключении. Результаты чтений от предыдущих подключений игнорируются. Для выхода нажми `Ctrl+C`.

## Проверено на Windows 11

| Устройство | Результат |
| --- | --- |
| `Node 75 HP-1` | Подключена по LE. GATT вернул 100%, как в настройках Windows. Характеристика Battery Level заявляет поддержку уведомлений. |
| `Xbox Wireless Controller` | Сопряжён и отключён. Селектор подключённых устройств исключил контроллер. |

Режим `--watch` прошёл ручную проверку. Фактическую доставку уведомлений GATT и работу с наушниками ещё предстоит проверить.

## Следующие этапы

1. Подписаться на уведомления GATT об изменении заряда. Для устройств без уведомлений добавить редкий опрос, пока они подключены.
2. Добавить иконки через `Shell_NotifyIconW`, восстановление после перезапуска Проводника, автозапуск через `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` и запуск одного экземпляра.
3. Проверить на Windows 11 x64 два поддерживаемых устройства одновременно, точность отображения после отключения одного из них, сна, переключения Bluetooth и повторного входа в систему.
4. Отдельно проверить наушники в Bluetooth-режиме и выяснить, доступен ли заряд через их USB-приёмник.
