# AccessoryBatteryTray

Утилита для Windows 11 x64. Открывает общую панель из трея и показывает заряд подключённых Bluetooth-аксессуаров, с которых удалось прочитать процент. Консольные режимы помогают проверить обнаружение, подключение и чтение заряда.

## Запуск

Нужен .NET 10 SDK. Выполняй команды в PowerShell из папки проекта.

Разовое перечисление подключённых Bluetooth Classic и LE устройств и чтение заряда через GATT для LE:

```powershell
dotnet run -- --diagnose
```

Режим также показывает сопряжённые устройства, исключённые селектором подключённых. При ошибке чтения выводит операцию и причину.

Чтобы сравнить системные изображения подключённых устройств, запусти диагностику значков:

```powershell
dotnet run -- --diagnose-icons
```

Команда выводит путь к временной папке и имена сохранённых PNG для каждого устройства. Файлы `*-glyph.png` получены через `GetGlyphThumbnailAsync`, а `*-thumbnail.png` — через `GetThumbnailAsync`. Если по системному идентификатору удалось открыть `DeviceContainer`, файлы `*-container-glyph.png` и `*-container-thumbnail.png` содержат изображения контейнера. Сравни их с тем, что показывает Windows в «Параметрах».

Наблюдение за подключениями через `DeviceWatcher`:

```powershell
dotnet run -- --watch
```

Режим выводит первоначальный список подключённых устройств, события подключения и отключения, а также результат чтения заряда LE при каждом подключении. После первого чтения он пытается подписаться на обновления заряда. Если подписка недоступна, а характеристику можно читать, режим опрашивает её раз в пять минут, пока устройство подключено. Результаты от предыдущих подключений игнорируются. Для выхода нажми `Ctrl+C`.

Оба режима используют `GattBatterySource` для поиска GATT Battery Service и Battery Level. Источник возвращает процент и состояние чтения через `BatteryReport`. `BluetoothConnectionMonitor` публикует события подключения, отключения и получения данных о заряде с идентификатором устройства. `BluetoothWatchConsole` отображает эти события в режиме `--watch`. Общий формат сообщений о заряде задаёт `BatteryConsoleText`.

### Иконки в трее

```powershell
dotnet run -- --tray
```

Общий значок батареи появляется после первого успешного чтения. Нажми на него, чтобы открыть панель реальных устройств. Процент виден рядом со значком, полное имя — при наведении. Для распознанных клавиатур, наушников и геймпадов панель использует контурные значки [Microsoft Fluent System Icons](https://github.com/microsoft/fluentui-system-icons) (24 px, Regular). Тип определяется по данным Bluetooth или категориям Windows. Для мышей и неизвестных типов панель использует системный значок контейнера, затем значок Bluetooth-записи и запасной силуэт. При отключении устройство исчезает из панели. Если список опустел, панель закрывается и значок пропадает. Windows может поместить значок в меню скрытых значков. Для выхода нажми `Ctrl+C` в консоли запуска.

### Общая панель на тестовых данных

```powershell
dotnet run -- --tray-preview
```

Нажми на общий значок батареи в трее. Панель показывает четыре тестовых устройства с процентом рядом с каждым монохромным силуэтом. При наведении видны полное имя и заряд. Для тестовой мыши используется запасной силуэт. Системный значок конкретной мыши можно увидеть с подключённой мышью в обычном режиме. Проверь, что панель открывается рядом со значком, помещается на текущем мониторе и закрывается по `Esc` или щелчку вне окна. После перезапуска Проводника общий значок должен вернуться, а панель снова открываться по нажатию. Для выхода нажми `Ctrl+C`.

Читаемость отдельных числовых иконок `0`, `9`, `30`, `99` и `100` можно по-прежнему проверить отдельно:

```powershell
dotnet run -- --tray-icon-preview
```

Пока режим числовых образцов работает, перезапусти «Проводник Windows» через Диспетчер задач и проверь, что все пять иконок снова появились. В обычном режиме при отсутствии поддерживаемых подключений трей остаётся без иконок утилиты.

## Структура проекта

- `Program.cs` разбирает аргументы и запускает выбранный сценарий.
- `Features/Bluetooth/Diagnose/` содержит сценарий разовой диагностики.
- `Features/Bluetooth/Watch/` содержит сценарий наблюдения за подключениями.
- `Features/Bluetooth/GattBatterySource.cs` содержит чтение и наблюдение GATT, общие для обоих сценариев.
- `Features/Tray/` отображает общую панель `AccessoryPanel`, регистрирует значок через `Shell_NotifyIconW` и восстанавливает его по сообщению `TaskbarCreated`.

## Проверено на Windows 11

| Устройство | Результат |
| --- | --- |
| `Node 75 HP-1` | Подключена по LE. GATT вернул 100%, как в настройках Windows. Характеристика Battery Level заявляет поддержку уведомлений. |
| `Xbox Wireless Controller` | Сопряжён и отключён. Селектор подключённых устройств исключил контроллер. |

События подключения и отключения в режиме `--watch` прошли ручную проверку. Для проверки обновлений запусти `--watch` с подключённой клавиатурой и дождись строки `GATT subscription active (Notify)`. При изменении уровня заряда без переподключения ожидается `Battery update: … (GATT notification)`. Фактическую доставку уведомлений, резервный опрос и работу с наушниками ещё предстоит проверить.

4. Отдельно проверить наушники в Bluetooth-режиме и выяснить, доступен ли заряд через их USB-приёмник.
