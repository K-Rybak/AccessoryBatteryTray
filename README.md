# AccessoryBatteryTray

Утилита для Windows 11 x64. Цель MVP — показывать в трее по одной иконке с зарядом для каждого подключённого Bluetooth-аксессуара, с которого удалось прочитать процент. Сейчас доступны два консольных режима для проверки обнаружения, подключения и чтения заряда.

## Запуск

Нужен .NET 10 SDK. Выполняй команды в PowerShell из папки проекта.

Разовое перечисление подключённых Bluetooth Classic и LE устройств и чтение заряда через GATT для LE:

```powershell
dotnet run -- --diagnose
```

Режим также показывает сопряжённые устройства, исключённые селектором подключённых. При ошибке чтения выводит операцию и причину.

Наблюдение за подключениями через `DeviceWatcher`:

```powershell
dotnet run -- --watch
```

Режим выводит первоначальный список подключённых устройств, события подключения и отключения, а также результат чтения заряда LE при каждом подключении. После первого чтения он пытается подписаться на обновления заряда. Если подписка недоступна, а характеристику можно читать, режим опрашивает её раз в пять минут, пока устройство подключено. Результаты от предыдущих подключений игнорируются. Для выхода нажми `Ctrl+C`.

Оба режима используют `GattBatterySource` для поиска GATT Battery Service и Battery Level. Этот класс отвечает за чтение заряда, подписку и опрос. `BluetoothDiagnostics` перечисляет устройства и выводит результаты разовой проверки. `BluetoothConnectionMonitor` следит за подключениями и запускает наблюдение за зарядом.

## Структура проекта

- `Program.cs` разбирает аргументы и запускает выбранный сценарий.
- `Features/Bluetooth/Diagnose/` содержит сценарий разовой диагностики.
- `Features/Bluetooth/Watch/` содержит сценарий наблюдения за подключениями.
- `Features/Bluetooth/GattBatterySource.cs` содержит чтение и наблюдение GATT, общие для обоих сценариев.

## Проверено на Windows 11

| Устройство | Результат |
| --- | --- |
| `Node 75 HP-1` | Подключена по LE. GATT вернул 100%, как в настройках Windows. Характеристика Battery Level заявляет поддержку уведомлений. |
| `Xbox Wireless Controller` | Сопряжён и отключён. Селектор подключённых устройств исключил контроллер. |

События подключения и отключения в режиме `--watch` прошли ручную проверку. Для проверки обновлений запусти `--watch` с подключённой клавиатурой и дождись строки `GATT subscription active (Notify)`. При изменении уровня заряда без переподключения ожидается `Battery update: … (GATT notification)`. Фактическую доставку уведомлений, резервный опрос и работу с наушниками ещё предстоит проверить.
